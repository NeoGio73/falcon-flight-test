# Chemistry Falcon: Flight Test

An extra-credit game for a non-majors chemistry course, covering Chapter 8 (Energy Storage) and Chapter 9 (Polymers and Plastics). Students fly from stop to stop, answer chemistry checks at each one, and finish with a downloadable completion certificate.

**Play:** https://neogio73.github.io/falcon-flight-test/

- **Computer:** keyboard and mouse (W/S throttle, A/D turn, arrow keys pitch).
- **Phone or tablet:** hold it sideways. Tilt to steer (on iPhone, tap Allow when asked about motion), slide the throttle bar, hold BOOST or BRAKE. A joystick appears if tilt isn't available, and ASSIST steers to the next ring.

At the end, students type their name on the victory screen, download the certificate (a PNG picture) and upload it to the D2L assignment dropbox.
